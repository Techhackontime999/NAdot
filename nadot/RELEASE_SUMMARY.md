## 🚀 **Quick Start**

### **For Users**
```bash
git clone https://github.com/Techhackontime999/NAdot.git
cd NAdot/NAdot
./deploy.sh development  # Unix/Linux/Mac
# OR
deploy.bat development   # Windows
```

### **For Production**
```bash
./deploy.sh production   # Unix/Linux/Mac
# OR
deploy.bat production    # Windows
```

## 📊 **Technical Specifications**

- **Backend**: Django 5.2.10, Python 3.10+
- **Database**: SQLite (dev), PostgreSQL (prod)
- **Real-time**: Django Channels + WebSockets
- **Frontend**: HTML5, CSS3, JavaScript, Tailwind CSS
- **Caching**: Redis support (optional)
- **Deployment**: Heroku, AWS, DigitalOcean ready
